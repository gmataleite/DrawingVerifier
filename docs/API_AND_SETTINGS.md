# DrawingVerifier - API, Vision Tiling & Settings Guide

This document describes how DrawingVerifier integrates with the Google Gemini API, how the high-resolution quadrant tiling pipeline operates, and how credentials are securely handled on Windows.

---

## 1. Google Gemini API Integration

DrawingVerifier uses the Google Gemini REST API (`v1beta/models/{model}:generateContent`) with native multimodal image and document capabilities.

### 1.1 Endpoint & Authentication
- **Endpoint:** `https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key={API_KEY}`
- **Authentication:** Query parameter `key` containing the user's Google AI Studio API key.

### 1.2 Request Configuration
DrawingVerifier configures the API payload to guarantee deterministic, machine-readable output:
- **`temperature: 0.0`**: Clamps sampling randomness to zero. This ensures the model outputs consistent, reproducible readings across subsequent runs of the same drawing.
- **`response_mime_type: "application/json"`**: Enforces JSON mode at the API level.
- **`response_schema`**: Injects the skill's JSON Schema into Gemini's grammar parser, preventing syntax errors or conversational filler text outside the JSON object.
- **`system_instruction`**: Injects the skill's domain-specific inspection strategy and verification guidelines.

### 1.3 Supported Models
Users can select their preferred Gemini model in the **Settings** dialog:
- **`gemini-3.8-flash` (Default):** Gold standard for high-speed multimodal extraction, precise visual reasoning, and agentic workflows. Recommended for standard verification operations.
- **`gemini-4-argon`:** Advanced deep reasoning and complex spatial logic. Ideal for intricate assemblies, non-standard geometric projections, or dense multi-view fabrication sheets.
- **`gemini-3.5-flash-lite`:** Ultra-efficient lightweight model optimized for high-throughput batch processing and lower token overhead.

## 2. High-DPI Quadrant Tiling (300 DPI)

### 2.1 The Problem with Large Mechanical Drawings
Mechanical drawings are standardly created in large paper formats (ISO A0: $841 \times 1189\text{ mm}$, A1: $594 \times 841\text{ mm}$, ANSI D/E). When directly passed as a single downscaled image, high-frequency details—such as decimal points (`12.5`), balloon numbers, and tolerance notes—can blur, resulting in extraction errors.

### 2.2 The Quadrant Tiling Architecture
When **Enable High-DPI Quadrant Tiling** is active:
1. `PdfRasterizerService` uses `PDFtoImage` to render the first page of the PDF into a raw high-resolution bitmap at **300 DPI** (typically exceeding $10,000 \times 7,000\text{ pixels}$).
2. An **Overview Image** is generated by compressing the full sheet at quality 80.
3. The high-res bitmap is split into **four spatial quadrants** with a **15% overlapping margin** along the central axes using SkiaSharp:
   - **Top-Left:** `(0, 0)` to `(width / 2 + overlapX, height / 2 + overlapY)`
   - **Top-Right:** `(width / 2 - overlapX, 0)` to `(width, height / 2 + overlapY)`
   - **Bottom-Left:** `(0, height / 2 - overlapY)` to `(width / 2 + overlapX, height)`
   - **Bottom-Right:** `(width / 2 - overlapX, height / 2 - overlapY)` to `(width, height)`

```
┌───────────────────────────────┬───────────────────────────────┐
│                               │                               │
│                               │                               │
│           QUADRANT 1          │          QUADRANT 2           │
│           (Top-Left)          │          (Top-Right)          │
│                               │                               │
│                   ┌───────────┼───────────┐                   │
│                   │ 15% Overlap Center    │                   │
├───────────────────┼───────────┼───────────┼───────────────────┤
│                   │ 15% Overlap Center    │                   │
│                   └───────────┼───────────┘                   │
│                               │                               │
│           QUADRANT 3          │          QUADRANT 4           │
│          (Bottom-Left)        │         (Bottom-Right)        │
│                               │                               │
│                               │                               │
└───────────────────────────────┴───────────────────────────────┘
```

4. All 5 images (Overview + 4 Quadrants) are encoded as high-quality JPEGs and passed as multipart `inline_data` items within a single multimodal prompt payload.
5. If rasterization fails for any reason, the system automatically falls back to transmitting the raw PDF base64.

## 3. Windows DPAPI Security & Storage

All local application data is stored in the user's roaming/local app data directory:
`%LocalAppData%\DrawingVerifier\`

```
%LocalAppData%\DrawingVerifier/
├── DrawingVerifier.db      # Embedded LiteDB database containing skills & rules
├── settings.dat            # DPAPI-encrypted Gemini API key (Hidden file)
└── appsettings.json        # Non-sensitive user preferences
```

### 3.1 DPAPI Encryption Details
- DrawingVerifier calls `ProtectedData.Protect(plainBytes, null, DataProtectionScope.CurrentUser)`.
- The encryption key is derived directly from the Windows logged-in user credentials and protected by the machine's Trusted Platform Module (TPM).
- The resulting file `settings.dat` is marked with the `FileAttributes.Hidden` attribute.
- Plaintext API keys never touch disk, application configuration files, or Windows Event logs.

### 3.2 Non-Sensitive Preferences (`appsettings.json`)
Preferences that do not require cryptographic protection are stored in human-readable JSON:
```json
{
  "EnableHighDpiTiling": true,
  "SelectedGeminiModel": "gemini-3.8-flash"
}
```

## 4. Troubleshooting API & Connection Issues

| Issue / Error Message | Probable Cause | Resolution |
| :--- | :--- | :--- |
| **`400 Bad Request: API key not valid`** | Invalid or mistyped API key. | Open **Settings**, verify your Google AI Studio key, and click **Save**. |
| **`403 Forbidden`** | API key lacks permission or billing is disabled for selected model. | Ensure Gemini API is enabled in your Google Cloud or AI Studio console. |
| **`429 Resource Exhausted / Quota Exceeded`** | Rate limit exceeded on free tier. | Wait 60 seconds before re-running or upgrade to a pay-as-you-go Gemini API tier. |
| **`Failed to deserialize Gemini JSON`** | Model returned invalid JSON or truncated output. | Switch model to `gemini-3.8-flash` or `gemini-4-argon` which have full JSON Schema support. |
| **`Spatial distance between balloon and dimension is unusually large`** | Visual misalignment between balloon leader line and dimension line. | Inspect drawing view manually to confirm leader line destination. |
